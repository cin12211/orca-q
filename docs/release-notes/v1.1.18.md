# 🎉 v1.1.18 - ERD Auto Layout, MongoDB Instance Insights & Faster Desktop Startup

## ✨ New Features

- **ERD Auto Layout**: Rearrange your ER diagram in one click from the diagram toolbar. Pick from five layouts: Default, Left to right, Pipeline, Snowflake and Compact. OrcaQ remembers the layout you chose.
- **MongoDB Instance Insights**: MongoDB connections now have Instance Insights with an Overview (version, uptime, connections and operation rates) and a Replication view showing replica set members and their state. If your user lacks the permission to read server status, OrcaQ tells you to grant the `clusterMonitor` role.

## 🔧 Improvements

- **Strict Mode Always Confirms Changes**: On a connection tagged with a Strict Mode tag, Safe Mode confirmations are always on, even when Safe Mode is off in Settings. This covers saving and deleting rows in Quick Query and actions from the Schemas context menu.
- **Copy the Production Phrase**: The Production Environment Warning now has a copy button next to the phrase you need to type.
- **Faster ER Diagrams**: Large ER diagrams open faster and stay smooth when you pan, zoom, hover or drag tables. Only the tables on screen are drawn.
- **Desktop Splash Screen**: The desktop app shows a splash screen as soon as it launches instead of a blank window, then opens OrcaQ when the local server is ready.
- **Faster Desktop Startup**: The desktop app caches compiled server code between launches, so later launches start faster.
- **Instance Insights by Database Family**: Instance Insights now opens the right panel for each database family (SQL, MongoDB, Redis, RabbitMQ, Kafka).
- **Star OrcaQ on GitHub**: After a few launches, OrcaQ asks once whether you would like to star the project on GitHub. Pick Later and it asks again after the next update. Pick No thanks and it never asks again.

## 🐛 Bug Fixes

- **Naming Query Files and Folders**: Backspace, Delete and the arrow keys now work while you name or rename a file or folder in the Raw Query explorer.
- **New Files in Closed Folders**: Creating a file inside a closed folder opens the folder and puts the cursor in the name field right away.
- **No More Jumping While Naming**: A new file or folder stays in place while you type its name, then moves to its sorted position once you confirm. The "Name cannot be empty" error no longer flashes as soon as you start.
