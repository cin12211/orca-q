# 🎉 v1.1.16 Changelog

## ✨ New Features

- **DuckDB Connections (Beta)**: Connect to a local `.duckdb` file from the desktop app. Browse schemas, tables and views, edit rows, and see foreign keys in the ER diagram. Read column types such as HUGEINT, DECIMAL, LIST, STRUCT, MAP, UUID and BLOB in the data grid.
- **DuckDB Raw Query**: Run DuckDB SQL with variables that leave list slices and struct literals alone. Large results stream instead of loading into memory, cancelling stops the running statement, and a long query no longer blocks schema browsing.
- **DuckDB Tools**: Compare two DuckDB files with Schema Diff, and check storage, attached databases and settings in Instance Insights.
- **DuckDB Macros**: DuckDB connections show a Macros section instead of Functions. List scalar and table macros per schema and open their definition. Read-only for now.
- **New Database File**: Create an empty SQLite or DuckDB database right from the connection form. Pick a name and a folder, and set options that are written to the file: journal mode, page size, encoding and auto vacuum for SQLite, storage compatibility and block size for DuckDB. Existing files are never overwritten.
- **MCP Read-Only DuckDB**: The built-in MCP server serves DuckDB files. Every query is read-only and cannot reach files outside the database, whatever the session's access level.
- **MotherDuck**: Added to the database list as coming soon.

## 🔧 Improvements

- **Clearer File Errors**: Choosing a file that is not a DuckDB database, or one locked by another program, now says so instead of failing vaguely.
- **Stable Test Hooks**: Connection, schema, data grid, raw query, ERD and database tool screens expose `data-testid` attributes for end-to-end tests.

## ⚠️ Known Limitations

- **DuckDB on Intel Mac**: DuckDB beta is not available on Intel Macs yet. The app shows it as unavailable there; Apple Silicon and Linux are supported.

## 🐛 Bug Fixes

- **False "Data saved successfully!"**: Saves and deletes refused by SQLite, MySQL, Oracle or DuckDB now show the database error instead of reporting success.
- **File Connections Missing Metadata**: Schema, ERD and reverse-schema requests now keep the file path, so local file connections load their metadata.

## 🔒 Security

- **Desktop Only DuckDB**: DuckDB SQL can read files on the machine running it, so the server refuses DuckDB connections and new database files outside the desktop app.
