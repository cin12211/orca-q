# 🎉 v1.1.17 Changelog

## ✨ New Features

- **SQL Server Connections (Beta)**: Connect with an ADO.NET string, a `sqlserver://` URI or the form. Works with SQL Server 2017+ and Azure SQL. Browse schemas, tables and views, edit rows in Quick Query, see the ER diagram, and compare schemas with Schema Diff.
- **SQL Server Raw Query**: Run T-SQL scripts with `GO` batch separators, including `GO 5` repeat counts. The result grid shows the last result set of a script.
- **CockroachDB Connections (Beta)**: Connect to CockroachDB v23.2+ with your usual `postgresql://` string. Quick Query, Raw Query, ER diagram and Schema Diff work, and the hidden `rowid` column stays out of the way.
- **Oracle Connections (Beta)**: Oracle is back as a connection type for Oracle 19c and newer. Browse schemas, tables and views, edit rows, run raw queries, and use the ER diagram and Schema Diff.
- **Instance Insights**: SQL Server and CockroachDB get a read-only overview with sessions, running statements and settings. Oracle keeps its read-only view.
- **MCP Server**: The built-in MCP server now serves SQL Server and CockroachDB. Read-only sessions cannot change data: CockroachDB runs in a read-only transaction, and SQL Server runs in a transaction that is always rolled back.

## 🔧 Improvements

- **Minimum Version Notice**: The connection form tells you the minimum server version for SQL Server, CockroachDB and Oracle. Older servers get a clear message when you test the connection.
- **Schema Diff SQL**: Generated SQL now matches the target database, with the right quoting and syntax for SQL Server, Oracle and MySQL.
- **Database Tools**: Tools a database does not support are simply left out.

## ⚠️ Known Limitations

- **SQL Server, CockroachDB and Oracle**: Users & Roles, AI Agent and Backup & Restore are not available yet. Instance Insights is read-only, so sessions cannot be cancelled or killed from OrcaQ.
- **SQL Server Sign-in**: Only SQL logins are supported for now, not Windows or Microsoft Entra ID.
- **CockroachDB Table Sizes**: CockroachDB does not expose table sizes, so they show as N/A.

## 🐛 Bug Fixes

- **Oracle Filters**: Quick Query filters on Oracle now apply their values.
- **Oracle Default Schema**: Oracle connections open on your own schema instead of a system schema.
- **Schema Diff on Form Connections**: Form-based connections no longer use a generated connection string, so passwords with special characters work.
