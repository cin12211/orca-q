# 🎉 v1.1.12 Changelog

## ✨ New Features

- **MongoDB Collection Filter**: Dual-mode filtering for MongoDB collection details supporting both an intuitive **Visual Rule Builder** (`Field` `Operator` `Value`) with column autocomplete suggestions and a **Raw BSON JSON Query** editor.
- **MongoDB Filter Hotkeys**: Complete keyboard navigation for collection filters:
  - `Meta+F` / `Ctrl+F`: Toggle filter bar and focus search input.
  - `Meta+Enter` / `Ctrl+Enter`: Apply all filter rules and execute query.
  - `Meta+I`: Add new visual filter rule row.
  - `Meta+Backspace`: Delete selected filter rule row.
  - `Esc`: Close filter bar.
- **MongoDB Schema Tree Navigation**: Streamlined sidebar tree navigation for MongoDB with dedicated database (`hugeicons:database`) and collection (`hugeicons:files-01`) icons, quick action menus (`View Database`, `View Collection`, `Create Collection`).
- **MongoDB Database Overview Grid**: Built-in AG Grid column filtering, sorting, and numeric byte-size comparators (`storageSize`, `dataSize`, `avgDocumentSize`, `totalIndexSize`).
- **MongoDB Collection Detail & Document Inspection**: Streamlined document viewing with Table view and List view integrated with `vue-json-pretty` for clear, interactive document inspection.
- **Document Quick Copy**: 1-click Copy button with visual feedback in the document header for copying complete JSON documents directly to clipboard.
- **Byte Size Formatting**: Refactored `formatBytes` helper to trim redundant decimal zeros (e.g. `38 KB` instead of `38.00 KB`).
