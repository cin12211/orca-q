# 🎉 v1.1.12 Changelog

## ✨ New Features

- **MongoDB Collection Filter**: Dual-mode filtering for MongoDB collection details supporting both an intuitive **Visual Rule Builder** (`Field` `Operator` `Value`) with column autocomplete suggestions and a **Raw BSON JSON Query** editor.
- **MongoDB Filter Hotkeys**: Complete keyboard navigation for collection filters:
  - `Meta+F` / `Ctrl+F`: Toggle filter bar and focus search input.
  - `Meta+Enter` / `Ctrl+Enter`: Apply all filter rules and execute query.
  - `Meta+I`: Add new visual filter rule row.
  - `Meta+Backspace`: Delete selected filter rule row.
  - `Esc`: Close filter bar.
- **MongoDB Raw Query Editor**: New `MongoQueryEditor` with a dedicated CodeMirror language extension (`mongoQueryLanguage`) for editing raw BSON filter queries with syntax highlighting.
- **MongoDB Schema Tree Navigation**: Streamlined sidebar tree navigation for MongoDB with dedicated database (`hugeicons:database`) and collection (`hugeicons:files-01`) icons, quick action menus (`View Database`, `View Collection`, `Create Collection`).
- **MongoDB Database Overview Grid**: Built-in AG Grid column filtering, sorting, numeric byte-size comparators (`storageSize`, `dataSize`, `avgDocumentSize`, `totalIndexSize`), and auto-sizing columns on collection list refresh.
- **MongoDB Collection Detail & Document Inspection**: Streamlined document viewing with Table view and List view integrated with `vue-json-pretty` for clear, interactive document inspection.
- **MongoDB Document In-Place Actions**: Edit document JSON directly in-place and remove documents with confirmation dialog.
- **Editor Settings Sync**: Synchronized theme and font size from editor settings for document List view (`VueJsonPretty`).
- **MongoDB Collection Table View**: Auto-sizing columns, JSON-value cells open a read-only `AgJsonCellEditor` popup for inspection, and a `scrollToTop` action.
- **Document Quick Copy**: 1-click Copy button with visual feedback in the document header for copying complete JSON documents directly to clipboard.
- **Byte Size Formatting**: Refactored `formatBytes` helper to trim redundant decimal zeros (e.g. `38 KB` instead of `38.00 KB`).

## 🐛 Bug Fixes

- **MongoDB Default Port**: Server-side Mongo connections resolved to port `5432` (Postgres' default) instead of `27017`, because `DEFAULT_PORTS` was duplicated across 4 places and 3 of them were missing a MongoDB entry.
- **MongoDB Connection String Round-Trip**: The backward scheme map had no `mongodb` entry, so the app generated `mongodb://...` connection strings it could not parse back.
- **D1 / Turso Icons**: `getDatabaseSupportByType` matched by bare type, so Cloudflare D1 and Turso connections rendered the plain SQLite icon everywhere except the create-connection modal. Icon resolution now takes the full connection.
- **MongoDB List View Scroll Jump**: Toggling a document's expand/collapse in the List view called `rowVirtualizer.measure()`, which resets every row's cached height, not just the toggled one — causing the scroll position to jump far from the row being viewed. Removed the manual reset; each row's own `measureElement` ResizeObserver already tracks its height change.

## ⚡ Refactors

- **Database Type Registry**: Consolidated per-type config (default ports, labels, aliases, connection-string schemes) that had drifted across multiple copies into a single registry, removing the compatibility shims (`getDatabaseSupportByType`, `DEFAULT_DB_PORTS`) and the redundant `db-connection/ports.ts` module.
