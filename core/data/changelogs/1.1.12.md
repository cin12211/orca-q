# 🎉 v1.1.12 Changelog

## ✨ New Features

- **Amazon Redshift & CockroachDB Support (Beta)**: Two new connection types, both wire-compatible with Postgres. Supports raw query execution, schema browser (tables, columns, views), and ERD.
  - Amazon Redshift: `redshift://user:password@host:5439/database`
  - CockroachDB: `cockroachdb://user:password@host:26257/database`
  - Row-Level Security, `CREATE RULE`, and triggers aren't supported by either engine and report as empty/disabled rather than erroring.

## 🔧 Improvements

- `PostgresAdapter`'s knex client is now overridable, letting Postgres-wire-compatible dialects reuse the same connection/query logic without duplicating it.
