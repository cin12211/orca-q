# 🎉 v1.1.13 Changelog

## ✨ New Features

- **System Schemas in Schema Selector**: PostgreSQL, MySQL and MariaDB now list built-in system schemas (`pg_catalog`, `information_schema`, `mysql`, `performance_schema`, `sys`) in the schema selector, grouped under a **System** section below your own schemas. Their tables and views load only when you select them.
- **Redis Group Overview**: Clicking a key-prefix folder in the Redis tree opens an overview tab with the group's key count, approximate memory usage and a table of its keys (`Key`, `Size`, `TTL`, `Data Type`), reusing the shared data grid.
- **Redis Selective Group Delete**: The group delete dialog now has a checkbox per key (plus select all), so you can uncheck the keys you want to keep instead of always deleting the whole matched set.
- **Raw Query JSON Preview on Read-only Results**: JSON cells in read-only results (for example the output of a function such as `SELECT fn_report()`) can now be opened in the JSON preview popup. Editing stays blocked for those cells.
- **MongoDB Insert & Export**: New insert and export modals for collections, with batch insert (arrays, NDJSON, comma-separated objects), export filename templates (`{collection}`, `{database}`, `{date}`, `{timestamp}`) and a syntax-highlighted query preview.
- **MongoDB Query Options**: More query options integrated with the collection filter, and a refined query control bar layout with the view-mode switcher.
- **Tree Search Auto-expand**: Searching in tree sidebars (Explorer, Redis keys, Agent history, ...) automatically expands matching folders and restores the previous expansion when the search is cleared.

## 🐛 Bug Fixes

- **PostgreSQL JSON Result Display**: `json` / `jsonb` values returned as an already-stringified string were shown as raw, escaped text in Raw Query results instead of pretty-printed JSON.
- **ERD Node Positions**: Collapsing or expanding a table no longer resets nodes you have dragged. Dragged positions are kept; the **Arrange** action still resets to the computed layout.

## ⚡ Performance

- **Lazy Schema Metadata**: On connect only lightweight schema names are fetched. A schema's tables, views and functions are loaded when you select it, and cached per connection and schema.
- **MongoDB Schemas Loading**: Merged the database and collection-name endpoints into a single `/api/mongodb/schemas` request with MongoClient caching, and batched collection-stats requests when folders expand.
- **MongoDB Tree Search**: Enhanced search across the MongoDB schema tree.

## ⚡ Refactors

- **FileTree**: Split the 1,100+ line `FileTree.vue` into focused composables (expansion, virtualization, selection, drag-and-drop, rename, keyboard navigation, focus).
- **MongoDB Editor & Enums**: Standardized enums, improved `BaseCodeEditor` and hardened import/export handling; removed the Table view mode and restored the row-index column in collection detail.
